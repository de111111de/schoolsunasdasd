# SCHOOLSUN — школа солнца ☀️

Образовательная платформа для школьников и учителей: курсы → уроки → тесты
с автопроверкой → домашние задания с проверкой учителем → прогресс, рейтинг
и сертификаты.

## Возможности

**Ученик**
- каталог курсов с поиском и фильтрами (предмет, класс), запись на курс
- уроки: теория в Markdown, видео с YouTube, вложения
- тесты: 6 типов вопросов (один/несколько вариантов, соответствие, число,
  краткий ответ, открытый ответ), таймер, ограничение попыток, автопроверка,
  разбор ответов после сдачи
- домашние задания: текст или файл, статусы «сдано / на доработку / принято»
  с комментарием учителя
- прогресс по курсу, лидерборд, PDF-сертификат при 100% прохождении
- тёмная тема «ночь со звёздами», анимации, адаптивная вёрстка

**Учитель**
- создание курсов и уроков (Markdown-теория, видео, вложения)
- визуальный конструктор тестов (JSON-конструктор с 6 типами вопросов)
- настройка домашних заданий с дедлайнами
- проверка домашних работ (баллы, статус, комментарий)
- проверка открытых ответов тестов
- таблица успеваемости, аналитика (средние баллы, самые сложные вопросы),
  экспорт успеваемости в CSV

**Администратор**
- управление пользователями (роли, блокировка)
- модерация курсов (публикация, удаление)

## Стек

- Java 21, Spring Boot 4 (Web MVC, Security, Data JPA, Validation, Thymeleaf)
- БД: H2 (файловый режим, по умолчанию) / PostgreSQL (профиль `postgres`)
- Flyway-миграции, BCrypt, CSRF-защита, rate limiting входа
- OpenPDF (сертификаты), commonmark (теория уроков)
- Фронт: собственный CSS (дизайн-система «рассвет», БЭМ) + ванильный JS

## Быстрый старт

Нужна только Java 17+ (Maven не требуется — есть wrapper).

```bat
mvnw.cmd spring-boot:run
```

или через собранный jar:

```bat
mvnw.cmd -DskipTests package
java -jar target\schoolsun-0.0.1-SNAPSHOT.jar
```

Открыть: **http://localhost:8080**

База (файл `data/schoolsun.mv.db`) и папка загрузок `uploads/` создаются
автоматически. При первом запуске наполняются демо-данные (курсы, уроки,
тесты, домашки, попытки, рейтинг).

## Курсы (15 шт., 7–11 класс)

По 3 курса на предмет (математика, физика, информатика, химия, биология).
В каталоге видны 12 общедоступных; **3 спецкурса** видны только по ссылке-приглашению:

| Спецкурс | Класс | Ссылка-приглашение |
|---|---|---|
| Олимпиадная физика | 10 | `/join/phys-olymp-26` |
| Алгоритмы и структуры данных | 11 | `/join/algo-pro-26` |
| Генетика: тайны наследственности | 11 | `/join/gen-pro-26` |

### Как работают ссылки-приглашения

1. Учитель открывает свой курс → галочка «Спецкурс (только по ссылке)» → на
   странице курса появляется блок «Ссылка-приглашение» с кнопками
   «Скопировать» и «Обновить».
2. Ссылку (например `http://localhost:8080/join/phys-olymp-26`) кидаем в
   школьный чат.
3. Ученик переходит: если не залогинен — сначала вход (после входа вернётся
   на ссылку автоматически), затем записывается на спецкурс одним кликом.
4. Без ссылки спецкурсы не найти: их нет в каталоге, а прямой URL отдаёт 404.

Вошедшему пользователю страницы `/login` и `/register` недоступны — они
перенаправляют в его кабинет.

## Переключение на PostgreSQL

1. Установить PostgreSQL и создать базу:

```sql
CREATE DATABASE schoolsun;
CREATE USER schoolsun WITH PASSWORD 'schoolsun';
GRANT ALL PRIVILEGES ON DATABASE schoolsun TO schoolsun;
```

2. Запустить с профилем:

```bat
java -jar target\schoolsun-0.0.1-SNAPSHOT.jar --spring.profiles.active=postgres
```

## Восстановление пароля

Демо-режим без почтового сервера: на странице «Забыли пароль» ссылка для
сброса показывается прямо на экране (действует 1 час).

## Структура

```
src/main/java/ru/schoolsun/
├── config/        SecurityConfig, rate limit
├── common/        обработчик ошибок, текущий пользователь, утилиты
├── user/          пользователи, регистрация, восстановление пароля
├── course/        курсы, каталог, запись
├── lesson/        уроки, вложения, прогресс, файлы
├── quiz/          тесты, вопросы, попытки, автопроверка, конструктор
├── homework/      домашние задания и проверки
├── rating/        лидерборд и аналитика
├── certificate/   сертификаты + генерация PDF
├── student/ teacher/ admin/   контроллеры по ролям
└── seed/          демо-данные при первом запуске
```

Шаблоны: `src/main/resources/templates/`, стили: `static/css/`
(дизайн-система в `tokens.css`), скрипты: `static/js/`.
